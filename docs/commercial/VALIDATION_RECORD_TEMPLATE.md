- [ ] 客户愿意推荐或复购。
- [ ] 标准化流程可复用。

### Pivot 信号

- [ ] 客户只愿意为人工整理服务付费，不关心软件产品。
- [ ] 客户主要购买中文源清洗、方法附录或模板，而不是完整审计包。
- [ ] 团队协作需求比单项目体检更强。
- [ ] 价格接受度只支持低价咨询，无法支撑产品化。

```text

```

### Stop 信号

- [ ] 客户不愿付款，也没有明确付费承诺。
- [ ] 已全额退款或取消订单，不能计入 Go 的真实付款数量，但应保留为失败原因证据。
- [ ] 客户认为现有免费工具或手工表格足够。
- [ ] 项目数据过于混乱，人工成本不可控。
- [ ] 客户要求超出安全或方法学边界。
