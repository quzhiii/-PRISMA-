### 强制边界

- 客户资料不得进入公开 Git 仓库。
- 客户资料不得写入 `docs/`、`tests/`、`fixtures/`、`literature-screening-v2.2/` 或其他产品资产目录。
- 不保存真实姓名、手机号、邮箱、付款账号或直接个人标识到验证记录。
- 不接收数据库账号、机构账号、Cookie、API key 或代理配置。
- 客户原始数据默认不得发送给远程 LLM、Agent、第三方 API 或遥测服务。
- 如需例外，必须有客户书面授权，并记录工具 / 服务商、数据范围、用途、保留期限和删除期限。
- 如需要展示样例，只能使用公开 demo 或客户明确允许的脱敏材料。
