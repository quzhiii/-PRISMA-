为什么选择 PRISMA WorkbenchWhy PRISMA Workbench

它不只是画一张图，而是保留支撑图表和研究结论的过程记录。It preserves the process behind diagrams and review outputs instead of only drawing the final figure.

来源与去重Sources and deduplication

混合导入，保守处理重复项Mixed-source import with conservative duplicate handling

支持常见数据库导出格式，硬重复自动移除，疑似重复保留人工核对。Common export formats are supported; hard duplicates are removed while candidates remain available for human checking.

双人复核Dual review

A/B 决定隔离，冲突由 resolver 处理Separate A/B decisions with resolver handling

浏览器内支持独立决定、冲突队列、一致性指标和未解决冲突导出门禁。The browser workflow supports separate decisions, conflict queues, agreement metrics, and an unresolved-conflict export gate.

可追溯导出Traceable exports

计数、决定和事件相互对应Counts connect to decisions and events

PRISMA 计数、排除理由、质量评价和复核证据可供研究者核对后用于方法附录。Researchers can verify PRISMA counts, reasons, quality appraisal, and review evidence before using them in methods appendices.

适合谁 / 使用场景Who it is for

适合需要正式筛选记录的个人研究者和复核团队。For individual researchers and review teams that need formal screening records.
