Start / Resume

先选一种起步方式，再进入筛选工作台。Choose a start path, then enter the screening workspace.

第一次使用可以先体验 Demo；正式项目请准备数据库导出的 CSV、RIS、NBIB 或 ENW 文件；已有项目可以从 JSON 备份恢复。进入工作台后，再选择单人筛选或双人独立筛选。项目记录默认保存在当前浏览器，需要分享时由你主动导出。First-time users can try the demo. Formal projects can start from CSV, RIS, NBIB, or ENW database exports. Existing projects can resume from a JSON backup. After entering the workspace, choose single review or dual independent review. Project records are saved in the current browser by default and shared by explicit export.

复核方式Review mode

双人模式通过本地文件交接 A/B 结果，适合同伴各自筛选后再合并。Dual mode hands off A/B results with local files, suitable for reviewers who screen separately and merge later.
